# Translations

Secopy speaks English and Spanish. Every word it shows comes from a catalog, so another language
is one file to translate. Reports and the CLI stay English: they are records people share and
search.

## Where the words are

- `ui/src/locales/en.json` — every word the app shows: screens, dialogs, notifications, the
  menu bar panel and icon, the native menus, and every message the app sends from Rust.
- `ui/src/lib/i18n.ts` — `t(key, values)` for the UI's own words; `ui/src/lib/message.ts` —
  `say(message)` for what Rust sends (`{ key, args }`).
- `crates/secopy-app/src/message.rs` — `msg!("key", name = value)` builds a message in Rust;
  `Message::text()` says it in the app's language (menus, the menu bar icon); `CATALOGS` lists
  the catalogs built into the app.

A value is a text with `{placeholders}`, or a plural: `{ "one": "{count} file", "other":
"{count} files" }` (the forms the language needs: `zero`, `one`, `two`, `few`, `many`,
`other`). Numbers and sizes are formatted for the language by the UI.

## Adding a language

1. Copy `en.json` to `<tag>.json` (`de.json`, `pt-BR.json`) and translate the values. Keep the
   keys and the `{placeholders}`; plural entries get the forms the language uses.
2. In `ui/src/lib/i18n.ts`, add it to `catalogs` (`import de from "../locales/de.json"`).
3. In `crates/secopy-app/src/message.rs`, add it to `CATALOGS`, and to `Numbers::of` if its
   number format isn't English's (as the UI's `Intl.NumberFormat`).
4. For macOS's own panels and the .secopy file type: add the tag to `CFBundleLocalizations` in
   `crates/secopy-app/Info.plist`, add `crates/secopy-app/infoplist/<tag>.lproj/InfoPlist.strings`,
   and list it under `bundle.macOS.files` in `tauri.conf.json`.
5. Run the tests: `cd ui && npx vitest run` and `cargo test -p secopy-app`. They fail on a
   missing or extra key, a placeholder English doesn't have, a plural form the language lacks,
   a catalog Rust or the bundle lacks, and any word written outside the catalog.

Settings › General › Language chooses the language (#181). Automatic, the default, is the
Mac's first language with a catalog, English otherwise, read from the system's own setting
(`NSGlobalDomain`), so a language Secopy chose never hides it. Rust keeps the language in use
(`message::language_in_use`); the windows ask for it before drawing and reload when Settings
change it; the menus are rebuilt. A new catalog needs its `language.name` (its own name) to
appear in the menu.

What stays in English on purpose: the name "Secopy", the window title, and the power assertion
macOS lists in `pmset -g assertions`.

## Writing new words

- UI: add the key to `en.json` and use `t("area.key")`. Never write words in a component; a test
  scans for them, and another fails on keys nothing uses.
- Rust: never send English to the UI. Build a `Message` with `msg!`; a test checks every key
  and its placeholders against `en.json`. A form error's key is `errors.field.<field>.…`, so
  the editor shows it under that field. No Rust code decides anything by text.
- The engine (`secopy-core`) keeps English `Display` texts for reports and the CLI, and gives
  its outcomes kinds; `crates/secopy-app/src/say.rs` turns kinds into messages.

## Terms

One word per thing, the same everywhere (#172). A translation keeps the same pairs: pick one
word for each term and never use it for anything else.

| Term | Means | Not | Spanish |
|---|---|---|---|
| source | what a copy reads: a directory or files | card, folder | origen |
| destination | where a copy or a mirror writes | backup, target | destino |
| origin | what a mirror keeps the destination identical to | source | origen |
| directory | a folder on a drive | folder | directorio |
| file | a file | — | archivo |
| job | one copy, mirror or verify that runs | task, transfer | tarea |
| copy (noun) | a job that copies; also the files it wrote | backup | copia |
| mirror | a job that keeps a destination identical to its origin | sync | espejo |
| verify / verifying | read files back and compare them with their checksums | check (as the action) | verificar |
| checksum | the XXH128 of a file's contents | hash | checksum |
| checksum file | the file listing each copied file with its checksum | hash file, manifest | archivo de checksums |
| deleted in the origin | a file a mirror finds gone from its origin | removed from, gone from | borrado en el origen |
| archive / archived | moved into the destination's `.secopy-archive` | trash | archivar / los archivados |
| delete / remove | delete: what a mirror or the user does on purpose; remove: take away | — | borrar / eliminar |
| cancel | what the user does to a running job | stop | cancelar |
| stopped | a job that couldn't go on (a full drive, a gone source) | cancelled | detenido |
| queue | the list of jobs that run one after another | batch | cola |
| preset | a saved setup: a copy preset or a mirror preset | profile, template | preajuste |
| options | what a copy is set up with (types, Also ignore) | settings | opciones |
| Settings | the app's settings screen | preferences | Ajustes |
| choose | pick a file, a directory or a value | pick, select | elegir |
| available | free space on a drive | free | disponible |
| symlink | a symbolic link | link, alias | enlace simbólico |
| same size and date | how a file already there is recognised; contents aren't compared | identical | mismo tamaño y fecha |

Spanish uses "tú", as macOS does, sentence case in menus too, and "los archivados" for the
archive, since "archivo" is a file. A copy's source and a mirror's origin are both "origen":
they never meet in one sentence.

## Style

- Few words on screens; the detail goes in the help (the ⓘ hints and button help).
- Complete sentences per case: a value is never a piece of another sentence. A placeholder is a
  name, a path, a number or a counted unit (`{size}`, `{days}` from `format.days`, `{removed}`
  from `mirror.preview.removedFiles`), so the words around it agree in any language.
- Curly quotes and apostrophes (“ ” ’), contractions (can't, couldn't, isn't).
- An ellipsis on what asks or opens something more: “Cancel…”, “+ New preset…”, “Edit…”.
- UI names in prose are quoted: press “Add to queue”, choose “Keep both”.
- Menus follow the platform: Title Case in English (Choose Source…, Cancel Job…).
