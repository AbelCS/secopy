# Translations

Secopy is written in English, and every word it shows comes from a catalog, so another language
is one file to translate. Reports and the CLI stay English: they are records people share and
search.

## Where the words are

- `ui/src/locales/en.json` — every word the app shows: screens, dialogs, notifications, the
  menu bar panel and icon, the native menus, and every message the app sends from Rust.
- `ui/src/lib/i18n.ts` — `t(key, values)` for the UI's own words; `ui/src/lib/message.ts` —
  `say(message)` for what Rust sends (`{ key, args }`).
- `crates/secopy-app/src/message.rs` — `msg!("key", name = value)` builds a message in Rust;
  `Message::text()` says it in the app's language (menus, the menu bar icon); `CATALOGS` lists
  the catalogs built into the app.

A value is a text with `{placeholders}`, or a plural: `{ "one": "{count} file", "other":
"{count} files" }` (the forms the language needs: `zero`, `one`, `two`, `few`, `many`,
`other`). Numbers and sizes are formatted for the language by the UI.

## Adding a language

1. Copy `en.json` to `<tag>.json` (`de.json`, `pt-BR.json`) and translate the values. Keep the
   keys and the `{placeholders}`; plural entries get the forms the language uses.
2. In `ui/src/lib/i18n.ts`, add it to `catalogs` (`import de from "../locales/de.json"`).
3. In `crates/secopy-app/src/message.rs`, add it to `CATALOGS`.
4. Run the tests: `cd ui && npx vitest run` and `cargo test -p secopy-app`. They fail on a
   catalog Rust lacks, a key with other placeholders, and any word written outside the catalog.

The app picks the Mac's first language it has a catalog for, English otherwise, in the UI and
in Rust alike. There is no setting until there is a second language.

What stays in English on purpose: the name "Secopy", the file associations and the window title
in `tauri.conf.json` (they need an `InfoPlist.strings` per language, added with the language),
and the power assertion macOS lists in `pmset -g assertions`.

## Writing new words

- UI: add the key to `en.json` and use `t("area.key")`. Never write words in a component; a test
  scans for them, and another fails on keys nothing uses.
- Rust: never send English to the UI. Build a `Message` with `msg!`; a test checks every key
  and its placeholders against `en.json`. A form error's key is `errors.field.<field>.…`, so
  the editor shows it under that field. No Rust code decides anything by text.
- The engine (`secopy-core`) keeps English `Display` texts for reports and the CLI, and gives
  its outcomes kinds; `crates/secopy-app/src/say.rs` turns kinds into messages.
