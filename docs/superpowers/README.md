# Specs and plans

How each feature was designed (`specs/`) and built (`plans/`), kept as records. They say what
was decided and why at the time; later changes are not written back into them. How Secopy
works now is in the [RFD](../rfd/0001-secopy.md) and the [user guide](../user-guide.md); what
comes next is in the [roadmap](plans/2026-09-26-v1-roadmap.md).
