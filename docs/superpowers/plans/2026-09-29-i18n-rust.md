# Translation Support, PR 2 (Rust sends codes) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** No English sentence travels from Rust to the UI: the app sends `Message { key, args }` codes and the UI turns them into words from `en.json`, so every text on screen can be translated.

**Architecture:** `crates/secopy-app/src/message.rs` defines `Message`/`Arg` and the `msg!` macro; `crates/secopy-app/src/say.rs` maps every engine type (FileError, FatalError, Blocker, scan/check problems, mirror guard/removals, io errors) to a `Message`. Commands return `Result<T, Message>`; DTO text fields become `Message`. The engine keeps its English `Display` for reports and the CLI, and gains structured kinds where it only had strings. The UI renders messages with `say()` (`ui/src/lib/message.ts`) and throws `AppError` for command errors. A Rust test proves every key the app can send exists in `en.json` with the same placeholders. `queue.json` stores a `Message`; an old string still loads as `errors.legacy`.

**Tech Stack:** Rust (serde, specta/tauri-specta, thiserror), Svelte 5, TypeScript, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-29-i18n-design.md` (section "Messages from Rust"). Inventory of every text: `docs/superpowers/plans/2026-09-29-i18n-rust-inventory.md` (E1–E62, F1–F17, N1–N5, X1–X3, B1–B4, S1–S4, C1–C5, M1–M3, R1–R2 are its ids).

## Global Constraints

- English stays the only language; the app reads as today, except the deliberate fixes listed under "English changes" below.
- Reports and the CLI stay English and byte-identical: every engine `Display` text stays; the existing report/CLI tests must pass unchanged.
- Keys are literal strings inside `msg!(...)` in Rust and literal strings in TS (unused-key and registry tests find them). Rust error keys live under `errors.*`; Rust-sent status words under the area that shows them (`queue.reason.*`, `import.*`, `mirror.preview.reason.*`…).
- Field errors (a form field's problem) use `errors.field.<field>.<what>` with `<field>` ∈ `name`, `source`, `origin`, `destination`, `days`: the editors route by that segment, never by wording.
- No Rust code decides by English text (no `starts_with`, `strip_prefix`, `match` on sentences, `full_stop`, capitalisation of translated text).
- OS error text (`io::Error` Display) is mapped by `ErrorKind` to `errors.os.*` keys; only an unmapped kind shows the raw OS text (`errors.os.other {text}`).
- Saved data: `queue.json` `lastError` becomes a `Message` object; a string still loads (`errors.legacy {text}`). Preset names Secopy makes (`Unnamed preset`, `{name} ({n})`) are saved data and stay as they are.
- Words rules: "directory" not "folder", "source" not "card", "presets".
- Commits: Conventional Commits, `Refs #84`, Co-Authored-By line, noreply author and committer.
- Checks before each commit: `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`, `cd ui && npx vitest run && npm run check`. Bindings: `SECOPY_UPDATE_BINDINGS=1 cargo test -p secopy-app ui_bindings_are_up_to_date` after a DTO change.

### English changes (deliberate, from the inventory's inconsistencies)

- Preflight file problems (`FileProblemView.reason`) are sentences like the other reasons ("A file with this name…" instead of "a file with this name…").
- "Not enough free space: 12.4 GB needed, 3.1 GB free" (sizes formatted, not raw bytes).
- E11 says "Connect the source again" (not "card").
- "1 checksum file problem" (singular); the not-durable queue reason ends with a full stop.
- The mirror preview's destination blocker is a sentence (capitalised).
- "{n} files" / "Retry: {n} failed files" use real plurals ("1 file").

## Review Focus

1. A Rust path that still sends English (a `String` field, `e.to_string()`, `format!` into a DTO) — the registry test can't see it; the reviewer greps `to_string()`/`format!` in `secopy-app/src` outside tests and reports.
2. A key sent with a placeholder the catalog text doesn't have, or missing one it has — the registry test (Task 1) and a sample render of every key (Task 8).
3. Old `queue.json` files: string `lastError`, missing key, `null`, an object from a newer version — Task 6 tests each.
4. Details lost on the way (paths, names, counts, hashes, OS reason) — each mapping test in Task 3 checks the args.
5. Reports/CLI text changing because an engine `Display` changed — existing report/CLI tests pin it; nothing in `report.rs`/`secopy-cli` is edited.

**Interfaces — produces:**

```rust
/// A text for the UI, as a catalog key and the values of its placeholders (#84).
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize, Type)]
pub struct Message { pub key: String, pub args: BTreeMap<String, Arg> }

/// A placeholder's value. Numbers are formatted by the UI for its language; `Size` as bytes
/// (formatBytes); `Message` is translated first; `List` is joined ("a, b").
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize, Type)]
#[serde(untagged)]
pub enum Arg { Number(f64), Text(String), List(Vec<Message>), Size { bytes: f64 }, Message(Box<Message>) }

pub struct Size(pub u64);                 // Into<Arg> → Arg::Size
impl From<&str|String|&Path|&PathBuf|u32|u64|usize|i64|Size|Message|Vec<Message>> for Arg
impl Message { pub fn raw(text: impl Into<String>) -> Message /* key "format.raw", arg text */ }
#[macro_export] macro_rules! msg { ($key:literal $(, $name:ident = $value:expr)* $(,)?) => … }
```

Paths go in as `Text` via `dto::show`. `msg!("errors.preset.gone")`, `msg!("errors.file.inTheWay", path = &p)`.

```ts
// ui/src/lib/message.ts
export function say(m: Message): string            // t(m.key as Key, values); Number → number, Text → string,
                                                   // Size → formatBytes, Message → say(), List → joined with format.comma
export class AppError extends Error { readonly m: Message }   // message = say(m)
export function fieldOf(e: unknown): string | null // "errors.field.<field>.…" → <field>
```

`api.ts` `unwrap` throws `new AppError(r.error)`; `messageOf(e)` keeps returning `e.message`.
