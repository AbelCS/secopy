# ASC MHL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** With Settings › Write ASC MHL on, every copy writes (or continues) an ASC MHL v2.0 history in the folder its files go to.

**Architecture:** A new `secopy_core::mhl` module holds everything about the format: C4, ignore patterns, reading a history, writing a generation, and `prepare`, which turns a resolved `Plan` into an `MhlPlan` (scopes, files to read, blockers). `run_job` gets `JobOptions::mhl` and, after the copy is durable, reads the extra files and writes each scope's generation, nested scopes first. The app keeps the setting, shows the plan line and blockers, the summary line, and undoes a written generation; the CLI gets `--mhl`.

**Tech Stack:** Rust (secopy-core, secopy-app with Tauri 2, secopy-cli), Svelte 5 UI; new crates `quick-xml`, `sha2`, `bs58`; `glob` (already in the workspace) moves into core's dependencies.

**Spec:** `docs/superpowers/specs/2026-10-01-asc-mhl-design.md` (issue #154)

## Global Constraints

- Optional: Settings › **Write ASC MHL**, off by default, independent of "Write the checksum file". CLI: `--mhl`.
- Copies only, never mirrors. Verify doesn't read MHL.
- Manifest: namespace `urn:ASC:MHL:v2.0`, `version="2.0"`; `<process>transfer</process>`; `<tool version="X.Y.Z">Secopy</tool>`; hashes `xxh64`, 16 lowercase hex; paths `/`-separated, relative to the scope.
- Manifest name `NNNN_<folder name>_<YYYY-MM-DD>_<HHMMSS>Z.mhl` (UTC, start of the job). Chain `ascmhl/ascmhl_chain.xml`, namespace `urn:ASC:MHL:DIRECTORY:v2.0`, `sequencenr` from 1 without gaps.
- C4: SHA-512 of the manifest bytes, base58 (alphabet `123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz`), left-padded with `1` to 88 characters, prefixed `c4`.
- Ignore list only grows; Secopy's patterns are added to the previous generation's.
- Nothing about a copy changes when the setting is off.
- Never write over or repair a history; a failed write leaves the history as it was.
- macOS only; i18n: every UI text in `ui/src/locales/en.json`, Rust sends `msg!` keys; regenerate bindings with `SECOPY_UPDATE_BINDINGS=1 cargo test -p secopy-app`.
- Commits: Conventional Commits, author and committer `3268106+AbelCS@users.noreply.github.com` exported in the same shell; gate every commit on `bash /tmp/i18n/checks.sh` exiting 0.

## Review Focus

1. A source history whose earlier hashes are md5/sha1/c4 only (made by another tool): Secopy can't verify them; its xxh64 is recorded `original` for those paths and the job is still Complete. Pinned in Task 4 (`another_format_is_recorded_as_original`).
2. A destination that already holds the same history the source brings (a copy run twice): not "two histories"; the source's `ascmhl` files aren't copied again and a generation is appended. Pinned in Task 5 (`the_same_history_twice_appends`).
3. A file name XML can't hold (control characters, not UTF-8): Start is blocked with the name, never a broken manifest. Pinned in Task 5 (`a_name_xml_cant_hold_blocks`).
4. Cancel then "Also remove the files already copied": the generation written is undone and the chain is back byte for byte. Pinned in Task 7 (`undo_reverts_the_mhl`).
5. A history changed between the plan and the end of the job (another tool appended): the write refuses instead of overwriting the chain. Pinned in Task 6 (`a_chain_changed_during_the_job_isnt_overwritten`).

```rust
use sha2::{Digest, Sha512};

const ALPHABET: &[u8; 58] = b"123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz";

/// `c4` and the SHA-512 of `bytes` as 88 base58 digits.
pub fn c4(bytes: &[u8]) -> String {
    let digest = Sha512::digest(bytes);
    let digits = bs58::encode(digest)
        .with_alphabet(&bs58::Alphabet::new(ALPHABET).expect("58 distinct ASCII digits"))
        .into_string();
    // bs58 writes a leading zero byte as one '1' each; C4 pads the number to 88 digits.
    let number = digits.trim_start_matches('1');
    format!("c4{number:1>88}")
}
```

Note: `bs58` keeps one `1` per leading zero byte, while C4 treats the digest as one big number padded to 88 digits. Trimming every leading `1` and re-padding to 88 gives C4's form in both cases.

```rust
//! What a history doesn't list: the standard's defaults, the system files Secopy skips, and
//! Secopy's own files (spec "What gets recorded").

use glob::{MatchOptions, Pattern};

/// The standard's defaults, then the system files Secopy never copies, then its own files.
pub fn secopy_patterns() -> Vec<String> {
    let mut patterns: Vec<String> = [".DS_Store", "ascmhl", "ascmhl/"]
        .into_iter()
        .map(String::from)
        .collect();
    patterns.extend(crate::system::NAMES.iter().map(|n| n.to_string()));
    patterns.extend(
        ["._*", "secopy_*.xxh64", "secopy_*.txt", "secopy_*.json"].map(String::from),
    );
    dedup(patterns)
}

/// `previous` first, then Secopy's patterns it lacks: the list only grows.
pub fn merged(previous: &[String]) -> Vec<String> {
    dedup(previous.iter().cloned().chain(secopy_patterns()).collect())
}

fn dedup(list: Vec<String>) -> Vec<String> {
    let mut seen = std::collections::HashSet::new();
    list.into_iter().filter(|p| seen.insert(p.clone())).collect()
}

pub struct Ignore {
    rules: Vec<Rule>,
}

struct Rule {
    glob: Pattern,
    anchored: bool,
    dirs_only: bool,
}

const OPTIONS: MatchOptions = MatchOptions {
    case_sensitive: true,
    require_literal_separator: true,
    require_literal_leading_dot: false,
};

impl Ignore {
    pub fn new(patterns: &[String]) -> Ignore {
        let rules = patterns
            .iter()
            .filter_map(|p| {
                let dirs_only = p.ends_with('/');
                let body = p.trim_end_matches('/');
                let anchored = body.contains('/');
                let glob = Pattern::new(body.trim_start_matches('/')).ok()?;
                Some(Rule { glob, anchored, dirs_only })
            })
            .collect();
        Ignore { rules }
    }

    /// `rel` is `/`-separated, relative to the scope. A path inside an ignored folder is
    /// ignored too.
    pub fn matches(&self, rel: &str, is_dir: bool) -> bool {
        let parts: Vec<&str> = rel.split('/').collect();
        (0..parts.len()).any(|end| {
            let last = end + 1 == parts.len();
            let as_dir = !last || is_dir;
            let prefix = parts[..=end].join("/");
            self.rules.iter().any(|r| {
                (!r.dirs_only || as_dir)
                    && if r.anchored {
                        r.glob.matches_with(&prefix, OPTIONS)
                    } else {
                        r.glob.matches_with(parts[end], OPTIONS)
                    }
            })
        })
    }
}
```

```rust
//! Writing a generation: the manifest first (a new file), then the chain (replaced whole), so
//! a failure never leaves a history pointing at nothing (spec "Writing safely").

use std::fmt::Write as _;
use std::fs::{self, OpenOptions};
use std::io::{self, Write};
use std::path::{Path, PathBuf};

use chrono::{DateTime, Local, SecondsFormat, Utc};

use super::{Action, ChainEntry, Generation, CHAIN, FOLDER};
use crate::hash::to_hex;

/// Characters XML 1.0 allows (a name with others can't be listed).
pub fn xml_can_hold(s: &str) -> bool {
    s.chars().all(|c| matches!(c, '\u{9}' | '\u{A}' | '\u{D}' | '\u{20}'..='\u{D7FF}'
        | '\u{E000}'..='\u{FFFD}' | '\u{10000}'..='\u{10FFFF}'))
}

fn esc(s: &str) -> String {
    s.replace('&', "&amp;").replace('<', "&lt;").replace('>', "&gt;")
        .replace('"', "&quot;").replace('\r', "&#13;")
}

fn date(t: DateTime<Local>) -> String {
    t.to_rfc3339_opts(SecondsFormat::Secs, false)
}

pub fn manifest_xml(g: &Generation) -> String {
    let mut x = String::from("<?xml version=\"1.0\" encoding=\"UTF-8\"?>\n");
    x.push_str("<hashlist version=\"2.0\" xmlns=\"urn:ASC:MHL:v2.0\">\n  <creatorinfo>\n");
    let _ = writeln!(x, "    <creationdate>{}</creationdate>", date(g.created));
    let _ = writeln!(x, "    <hostname>{}</hostname>", esc(&g.hostname));
    let _ = writeln!(x, "    <tool version=\"{}\">Secopy</tool>", esc(&g.tool_version));
    x.push_str("  </creatorinfo>\n  <processinfo>\n    <process>transfer</process>\n    <ignore>\n");
    for p in &g.ignore {
        let _ = writeln!(x, "      <pattern>{}</pattern>", esc(p));
    }
    x.push_str("    </ignore>\n  </processinfo>\n");
    let mut records: Vec<_> = g.records.iter().collect();
    records.sort_by(|a, b| a.rel.cmp(&b.rel));
    if !records.is_empty() {
        x.push_str("  <hashes>\n");
        for r in records {
            let modified = r.modified.map(|m| {
                format!(" lastmodificationdate=\"{}\"", date(DateTime::<Local>::from(m)))
            });
            let action = match r.action {
                Action::Original => "original",
                Action::Verified => "verified",
                Action::Failed => "failed",
            };
            let _ = write!(
                x,
                "    <hash>\n      <path size=\"{}\"{}>{}</path>\n      <xxh64 action=\"{action}\">{}</xxh64>\n    </hash>\n",
                r.size, modified.unwrap_or_default(), esc(&r.rel), to_hex(r.xxh64)
            );
        }
        x.push_str("  </hashes>\n");
    }
    if !g.references.is_empty() {
        x.push_str("  <references>\n");
        for r in &g.references {
            let _ = write!(
                x,
                "    <hashlistreference>\n      <path>{}</path>\n      <c4>{}</c4>\n    </hashlistreference>\n",
                esc(&r.path), r.c4
            );
        }
        x.push_str("  </references>\n");
    }
    x.push_str("</hashlist>\n");
    x
}

pub fn chain_xml(entries: &[ChainEntry]) -> String {
    let mut x = String::from(
        "<?xml version=\"1.0\" encoding=\"UTF-8\"?>\n<ascmhldirectory xmlns=\"urn:ASC:MHL:DIRECTORY:v2.0\">\n",
    );
    for e in entries {
        let _ = write!(
            x,
            "  <hashlist sequencenr=\"{}\">\n    <path>{}</path>\n    <c4>{}</c4>\n  </hashlist>\n",
            e.sequence, esc(&e.file), e.c4
        );
    }
    x.push_str("</ascmhldirectory>\n");
    x
}

pub fn manifest_name(sequence: u32, folder: &str, started: DateTime<Utc>) -> String {
    format!("{sequence:04}_{folder}_{}.mhl", started.format("%Y-%m-%d_%H%M%SZ"))
}

/// What `append` wrote, so `revert` can take it back.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Written {
    pub manifest: PathBuf,
    pub c4: String,
    pub chain: PathBuf,
    /// The chain as it was (`None`: there was none).
    pub chain_before: Option<Vec<u8>>,
    pub created_folder: bool,
}

/// Appends `g` to the history at `scope`, whose chain was `chain_before` (its bytes, `None`
/// for a new history) with `entries_before`. Refuses (`AlreadyExists`) when the chain on disk
/// isn't `chain_before` any more: someone else wrote to the history.
pub fn append(
    scope: &Path,
    chain_before: Option<&[u8]>,
    entries_before: &[ChainEntry],
    g: &Generation,
    started: DateTime<Utc>,
) -> io::Result<Written> {
    let folder = scope.join(FOLDER);
    let chain = folder.join(CHAIN);
    let on_disk = match fs::read(&chain) {
        Ok(b) => Some(b),
        Err(e) if e.kind() == io::ErrorKind::NotFound => None,
        Err(e) => return Err(e),
    };
    if on_disk.as_deref() != chain_before {
        return Err(io::Error::new(io::ErrorKind::AlreadyExists, "the ASC MHL history changed"));
    }
    let created_folder = match fs::create_dir(&folder) {
        Ok(()) => true,
        Err(e) if e.kind() == io::ErrorKind::AlreadyExists && folder.is_dir() => false,
        Err(e) => return Err(e),
    };
    let sequence = entries_before.len() as u32 + 1;
    let name = scope.file_name().map(|n| n.to_string_lossy().into_owned()).unwrap_or_default();
    let manifest = folder.join(manifest_name(sequence, &name, started));
    let text = manifest_xml(g);
    let c4 = super::c4::c4(text.as_bytes());
    let written = Written {
        manifest: manifest.clone(),
        c4: c4.clone(),
        chain: chain.clone(),
        chain_before: chain_before.map(<[u8]>::to_vec),
        created_folder,
    };
    let result = (|| {
        // Never through a link, never over a file.
        let mut f = OpenOptions::new().write(true).create_new(true).open(&manifest)?;
        f.write_all(text.as_bytes())?;
        crate::os::sync_durable(&f)?;
        let mut entries = entries_before.to_vec();
        entries.push(ChainEntry {
            sequence,
            file: manifest.file_name().expect("a name").to_string_lossy().into_owned(),
            c4,
        });
        replace(&chain, chain_xml(&entries).as_bytes())?;
        crate::os::sync_dir(&folder)
    })();
    match result {
        Ok(()) => Ok(written),
        Err(e) => {
            let _ = revert(&written);
            Err(e)
        }
    }
}

/// Writes `path` whole: a temporary name next to it, synced, renamed over it.
fn replace(path: &Path, bytes: &[u8]) -> io::Result<()> {
    let tmp = path.with_file_name(format!(".{CHAIN}.{}.secopy-tmp", std::process::id()));
    let result = (|| {
        let mut f = OpenOptions::new().write(true).create_new(true).open(&tmp)?;
        f.write_all(bytes)?;
        crate::os::sync_durable(&f)?;
        fs::rename(&tmp, path)
    })();
    if result.is_err() {
        let _ = fs::remove_file(&tmp);
    }
    result
}

/// Takes back what `append` wrote: the chain as it was, the manifest gone, and the folder if
/// it made it (and it's empty).
pub fn revert(w: &Written) -> io::Result<()> {
    match &w.chain_before {
        Some(bytes) => replace(&w.chain, bytes)?,
        None => match fs::remove_file(&w.chain) {
            Err(e) if e.kind() != io::ErrorKind::NotFound => return Err(e),
            _ => {}
        },
    }
    match fs::remove_file(&w.manifest) {
        Err(e) if e.kind() != io::ErrorKind::NotFound => return Err(e),
        _ => {}
    }
    if w.created_folder {
        let _ = fs::remove_dir(w.chain.parent().expect("ascmhl"));
    }
    Ok(())
}
```

```rust
// (History and Damage as in Interfaces.)

pub fn read(scope: &Path) -> Result<Option<History>, Damage> {
    let folder = scope.join(FOLDER);
    match fs::symlink_metadata(&folder) {
        Err(_) => return Ok(None),
        Ok(m) if !m.is_dir() => return Err(Damage::NoChain),
        Ok(_) => {}
    }
    let chain_bytes = fs::read(folder.join(CHAIN)).map_err(|_| Damage::NoChain)?;
    let entries = chain_entries(&chain_bytes).ok_or(Damage::ChainUnreadable)?;
    if entries.iter().enumerate().any(|(i, e)| e.sequence as usize != i + 1) {
        return Err(Damage::Gap);
    }
    let mut history = History {
        scope: scope.to_path_buf(),
        chain_bytes,
        entries: entries.clone(),
        recorded: HashSet::new(),
        first_xxh64: HashMap::new(),
        ignore: super::ignore::standard_defaults(),
    };
    for e in &entries {
        // The chain names files in the ascmhl folder only.
        if e.file.contains('/') || e.file.contains('\\') || e.file.starts_with('.') {
            return Err(Damage::Unreadable(e.file.clone()));
        }
        let bytes = fs::read(folder.join(&e.file)).map_err(|_| Damage::Missing(e.file.clone()))?;
        if super::c4::c4(&bytes) != e.c4 {
            return Err(Damage::Altered(e.file.clone()));
        }
        let m = manifest(&bytes).ok_or_else(|| Damage::Unreadable(e.file.clone()))?;
        for (path, xxh64) in m.hashes {
            history.recorded.insert(path.clone());
            if let Some(h) = xxh64 {
                history.first_xxh64.entry(path).or_insert(h);
            }
        }
        if let Some(ignore) = m.ignore {
            history.ignore = ignore;
        }
    }
    Ok(Some(history))
}
```

```rust
    Unlistable { path: PathBuf },
```

How `prepare` works (write it in this order, one helper each):

1. **Source histories:** if `source_dir` is `Some`, find every folder under it (itself included) that has an `ascmhl` entry, from `plan.files` (`entry.source` paths whose parent's name is `ascmhl` and file name `ascmhl_chain.xml`), plus `source_dir/ascmhl` itself. Read each with `read::read`; `Err(d)` → `Damaged`. Map each to its destination scope: `copy_root.join(sub)` where `sub` is its path relative to `source_dir`.
2. **Destination histories:** walk `copy_root` (if it exists) with `walkdir` (no links followed), collecting folders that hold an `ascmhl` and every file (relative `/`-path, size). Read each history; `Err` → `Damaged`.
3. **Scopes:** the union of both maps plus `copy_root` itself, sorted deepest first. For a scope with both:
   - if the source chain's entries are a prefix of (or equal to) the destination's → the same history: every plan file under `<source scope>/ascmhl/` gets `action = PlanAction::SkipIdentical`;
   - otherwise → `TwoHistories`.
4. **Leaves out:** for each source history, every path in `recorded` that isn't a planned file's `rel` (relative to its scope, `/`-separated), and isn't ignored by `Ignore::new(&history.ignore)` → `LeavesOut` (once per scope). Also `LeavesOut` when a source history's own files (`ascmhl/*`) aren't all in `plan.files` (a type filter dropped them).
5. **Overwrites:** each plan file with `PlanAction::Overwrite` whose path relative to its deepest scope is in that scope's destination history `recorded` → `OverwritesRecorded`.
6. **Unlistable:** each plan file whose `final_rel` isn't valid UTF-8 or fails `xml_can_hold` → `Unlistable`. Same for files found in step 2.
7. **To read:** files from step 2 that the job doesn't write (no plan file with `action.writes()` and that `final_rel`), not ignored (the scope's merged ignore list), and not recorded by their deepest scope's destination history or source history.

Blockers come back all at once (`Err(vec)`), so the UI can show the first and the CLI all.

  - `JobOptions::mhl: Option<MhlJob>` with `pub struct MhlJob { pub plan: MhlPlan, pub tool_version: String }` (default `None`).
  - `JobReport` gains `mhl_written: Vec<Written>`, `mhl_error: Option<IoFailure>`, `mhl_failed: Vec<PathBuf>` (rel paths, from the copy root, of `failed` records), `mhl_off: bool`.
  - `JobReport::is_success` also requires `mhl_error.is_none() && mhl_failed.is_empty()`.
  - `Progress` gains `pub recording: Option<Recording>` with `pub struct Recording { pub bytes: u64, pub total: u64 }`.
  - `mhl::run::record(plan: &Plan, job: &MhlJob, outcomes: &[FileOutcome], control: &JobControl, progress: &dyn Fn(u64)) -> Recorded` with `pub struct Recorded { pub written: Vec<Written>, pub error: Option<IoFailure>, pub failed: Vec<PathBuf> }`.

`record`:
1. Started time: `Utc::now()`, `Local::now()`, `hostname()` (via `libc::gethostname`, lossy UTF-8; empty on error).
2. Read each `to_read` file with `hash_from_device(path, 1 << 20, &|b| progress(done + b), control)`; any error (or a stop) → `error`, nothing written.
3. Records: each outcome with status `Copied`/`Verified` and a hash, at `plan.dest.join(final_rel)`; plus each read file. For each, the deepest scope; `rel` from that scope; `size` and `modified` from `fs::symlink_metadata` of the destination file; action: the scope's history (destination's, else source's) `first_xxh64[rel]` → equal `Verified`, different `Failed` (push to `failed`), absent `Original`.
4. Write deepest scope first: `chain_before`/`entries_before` from the destination history, or from the source history (its files arrived with the copy), or `None`/`[]`; `ignore: merged(&history.ignore or [])`; references: for each scope written already that lies inside this one, `Reference { path: <manifest path relative to this scope, '/'>, c4 }`. On an error: revert everything written in this job (reverse order) and return the error.
5. Before writing, re-read each scope's history with `read::read` and compare its `chain_bytes` with the plan's; a difference → error "the ASC MHL history changed" (also caught by `append`'s own check).

In `run_job`, after `make_durable` and only when `opts.mhl` is `Some`, `!control.is_stopped()` is not required (cancel keeps the checksum file's rules), but `fatal.is_none()` is:

```rust
let recorded = match (&opts.mhl, &fatal) {
    (Some(job), None) => {
        let total = job.plan.to_read_bytes;
        Some(crate::mhl::run::record(plan, job, &outcomes, control, &|bytes| {
            runner.set_recording(bytes, total)
        }))
    }
    _ => None,
};
```

(`runner.set_recording` stores the numbers so `emit_progress` puts `recording: Some(..)` in the next `Progress`, and emits one.) Move the `outcomes` extraction so `runner` is still alive for this, or pass a small closure that emits `Event::Progress` directly; keep whichever is simpler once the code is open.

## Rulings made while planning (carry into the spec in Task 12)

- The source's `ascmhl` folder is copied by the normal copy (verified, durable, undoable) and then appended to, instead of "copied by Secopy itself": same result, no second copy path. When the destination already has that history, the source's history files are marked already there (`SkipIdentical`) so they aren't copied over it.
- A path an existing history recorded only in another format (md5, sha1, c4) gets Secopy's xxh64 as `original`: Secopy can't compute those formats, so that file isn't verified against its earlier hash (noted in "Not now").
- `hashdate` is left out (it then means the manifest's `creationdate`).
- A copied file's `lastmodificationdate` is the destination file's (the source's date, which Secopy keeps).
