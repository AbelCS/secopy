## P2: lower risk

- Archive: cleanup errors never reported; age from the folder name in local time (time zones, wrong clock, DST hour); two runs in the same second can share a run directory and `finish` renames with replace.
- Jobs: keep-awake ends before removals, undo and reports, and preview deep checks have none; the queue lock is held while deleting an archive (window freezes); Start can race a queue start; quitting mid-queue records a cancelled job as "Stopped"; quitting after "Cancel + remove" drops the removal (`store` instead of `fetch_or`); an undo that can't remove the checksum file is hidden.
- Engine: cluster slack not in the space check (many small files on exFAT); permissions without the owner read bit break verify; FIFOs and sockets silently skipped in directory mode; a growing file in the small-file lane is read into memory unbounded; no checksum file and no error when every file was skipped.
- State: files from a newer Secopy are set aside as `.damaged-*` and replaced by defaults (only on a downgrade); queued copy entries drop fields a newer version added; Start and Add to queue don't check a pending scan in Rust (the UI does); CLI mirror dry-run counts failing files as unchanged; mirror presets can be edited while a job runs (only the UI prevents it).
- UI: the menu bar panel can apply an older view over a newer one; stuck on "Done" if the summary fails to load; Esc in a Dialog also closes the screen behind it; Dialog doesn't trap focus; FinishedList has no `.catch`; destination responses aren't ordered (tiny window, Start is off meanwhile).
- Mirror (from the #114 review): a case-sensitive origin with `Clips/` and `clips/` shares one directory on a case-insensitive destination; a file that reappears in the origin during a run is kept as the old version until the next run.
- Other processes writing into the destination during a job (GPT-6 Sol): check-then-rename fallback race, a parent directory swapped for a symlink, a same-size in-place rewrite on FAT, Verify's post-read race. Only with another app writing the same paths.
